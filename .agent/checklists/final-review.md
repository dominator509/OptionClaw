# Final Review Checklist

Before final response:

- [ ] Every active ExecPlan milestone is complete.
- [ ] All acceptance criteria are met or a STOP condition is documented.
- [ ] Required validation commands pass.
- [ ] `git diff --name-only` run.
- [ ] Changed files match expected files or extras are justified in Decision Log.
- [ ] Docs updated for behavior/config/security/deployment changes.
- [ ] No secrets in diff.
- [ ] No production data in diff.
- [ ] No live trading or fund movement introduced outside scope.
- [ ] Remaining risks documented.
- [ ] Outcomes & Retrospective updated.
- [ ] Final response lists ExecPlan, changed files, commands, results, decisions, assumptions, risks, and production-readiness status.
