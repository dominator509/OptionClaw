# Implementation Checklist

For every milestone:

- [ ] Read `AGENTS.md`, `COMMANDS.md`, `.agent/PLANS.md`, and the active ExecPlan.
- [ ] Read files listed for the milestone before editing.
- [ ] Inspect existing patterns, imports, tests, and commands.
- [ ] Implement only the milestone scope.
- [ ] Do not broaden scope or perform unrelated cleanup.
- [ ] Do not invent APIs, commands, config keys, environment variables, or schemas.
- [ ] Add or update tests with the behavior change.
- [ ] Run the milestone validation command.
- [ ] Expected validation result observed.
- [ ] Update ExecPlan Progress.
- [ ] Record surprises, assumptions, and decisions.
- [ ] Continue to next milestone unless a STOP condition applies.
