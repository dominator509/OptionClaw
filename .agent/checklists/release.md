# Release Checklist

- [ ] Version selected.
- [ ] Changelog or release notes updated.
- [ ] Release candidate criteria satisfied.
- [ ] `./scripts/verify.sh` passes.
- [ ] Dependency audit reviewed.
- [ ] No secrets or production data in diff.
- [ ] Build artifact created.
- [ ] Staging/paper deployment completed if applicable.
- [ ] Staging smoke test passes.
- [ ] Rollback artifact available.
- [ ] Production deploy approval obtained if deploying.
- [ ] Production smoke test passes.
- [ ] Monitoring/health checked after deploy.
- [ ] Remaining risks recorded.
